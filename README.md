# 🎓 Quiz Master

A full-featured online quiz platform where teachers create quizzes and students take them — with time-based rules, auto-grading, and a beautiful modern UI.

## ✨ Features

### 👨‍🏫 For Teachers
- ✅ Register as a teacher
- ✅ Create quizzes with **time windows** (opens/closes)
- ✅ **Smart duration system** (Auto / Custom / No Limit)
- ✅ Add multiple-choice questions (A, B, C, D)
- ✅ View all student submissions with scores
- ✅ Edit/delete own quizzes

### 👨‍🎓 For Students
- ✅ Register as a student
- ✅ Browse all available quizzes
- ✅ See quiz status (Upcoming / Available / Closed)
- ✅ Take quiz with **countdown timer**
- ✅ **Auto-submit** when timer expires
- ✅ Instant score and detailed results
- ✅ Track all past attempts

### 🎯 Time-Based Rules (Professional Exam Behavior)
- ⏰ Quiz opens/closes at specific times
- ⏱️ Per-attempt duration (Auto/Custom/No Limit)
- 🚫 **Can't take before/after the window**
- 🚫 **Can take only once**
- 📊 Auto-graded scoring

## 🛠️ Technologies Used

- **Backend:** Flask (Python)
- **Database:** SQLite with SQLAlchemy
- **Authentication:** Flask-Bcrypt, Sessions
- **Roles:** Teacher / Student (role-based access)
- **Frontend:** Bootstrap 5, Font Awesome, Plus Jakarta Sans, Jinja2
- **Deployment:** Render
- **Version Control:** Git & GitHub
